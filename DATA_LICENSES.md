# Dataset and Artifact Licensing

This repository contains source code, experiment configurations, derived metrics, tables, scripts, and reproducibility artifacts for long-context language model evaluation.

The original benchmark datasets used by this project may be governed by their own licenses or terms of use, including but not limited to HotpotQA, 2WikiMultiHopQA, LongBench, BABILong, and RULER-style synthetic tasks.

Unless explicitly stated otherwise, this repository does not relicense third-party datasets. Users are responsible for complying with the original dataset licenses and terms of use.

Processed files included for reproducibility are provided only to the extent permitted by the original data sources. When possible, this repository provides preprocessing scripts, configuration files, checksums, manifests, derived metrics, and experiment outputs rather than redistributing full third-party datasets.

Model outputs and aggregate metrics are provided for research reproducibility. Any redistribution or reuse of benchmark-derived artifacts should respect the licenses and terms of the corresponding original datasets.
